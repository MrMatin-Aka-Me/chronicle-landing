# Хроника — лендинг

Статическая страница для проверки интереса к Хронике до запуска. Один файл `index.html`, шрифты лежат рядом, сборка не нужна.

Страница не собирает персональных данных: нет форм, cookie, аналитики и запросов к сторонним сервисам (шрифты свои, не Google Fonts). Поэтому согласие на обработку данных и баннер cookie не нужны. Если добавите форму, счётчик или внешний скрипт, это перестанет быть так.

## Настройка

В конце `index.html` есть блок `Settings`:

```js
var LINKS={
  hero:'',     // пригласительная ссылка Telegram «Сайт, верх»
  general:'',  // пригласительная ссылка Telegram «Сайт, низ»
  app:''       // адрес входа в приложение; пусто — кнопки «Войти» нет
};
```

Пока ссылка пустая, её кнопка скрыта. Две разные пригласительные ссылки нужны, чтобы в статистике канала было видно, откуда пришёл подписчик: из первого экрана или из конца страницы.

## Проверить локально

Открыть `index.html` в браузере. Или `npx serve .` и http://localhost:3000.

## Выложить

Подойдёт любой статический хостинг: корень репозитория — корень сайта.
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root. На бесплатном тарифе GitHub работает только для публичных репозиториев.
- **Vercel / Netlify:** импортировать репозиторий, framework — Other, без команды сборки.
